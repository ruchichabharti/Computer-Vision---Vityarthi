# SmartVision — Project Statement

## Problem Statement
Manual inspection of images and videos to identify and count objects is time-consuming and can be inconsistent. SmartVision provides a command-line computer vision pipeline that detects objects, optionally tracks them in video, and produces count summaries.

## Scope
The project covers image detection, video detection/tracking, object counting, result export, validation, and basic automated tests. It is intended as an academic Computer Vision demonstration.

## Target Users
- Students learning Computer Vision
- Faculty/evaluators testing a reproducible CV application
- Developers experimenting with object detection pipelines

## High-Level Features
1. YOLO-based object detection.
2. Image annotation and output generation.
3. Video tracking.
4. Video object counting.
5. CSV analytics summaries.
6. Input validation and automated tests.

## Inputs and Outputs
Inputs are local image/video files and optional model/confidence settings. Outputs include annotated media and CSV summaries.
